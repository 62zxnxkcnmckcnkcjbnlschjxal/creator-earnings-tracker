最后更新日期：2026年9月12日
非官方工具 · 个人自用
本工具为个人开发并维护的非官方工具，仅供开发者个人使用。本工具与网易公司（NetEase, Inc.）、thatgamecompany, Inc.（TGC）及其关联公司均不存在任何形式的隶属、合作、授权或关联关系。

一、数据收集范围

本工具不设置账号注册与登录体系，也不会收集您的个人身份信息（如姓名、手机号、邮箱等）。

  • 业务数据（Cloudflare KV 云端同步）：活动内容、奖励信息、公示记录等业务状态数据，通过 /api/state 接口存储在 Cloudflare KV。数据为全局共享状态，不区分用户身份。
  • 界面偏好（浏览器本地存储）：播放器设置、各模块折叠/展开状态等仅保存在浏览器 localStorage 中，不会上传到任何服务器。
  • DeepSeek 对话数据：API Key 仅保存在浏览器本地，对话通过 Cloudflare Function 透明转发至 api.deepseek.com，本工具服务器不存储对话内容。
  • 音乐播放：页面嵌入了网易云歌单播放器，本工具不采集、不存储与音乐播放相关的任何用户数据。

二、数据安全与第三方传输

除 DeepSeek API 请求转发和音乐播放器嵌入外，本工具不会将您的任何数据主动传输给第三方。Cloudflare KV 数据存储在 Cloudflare 的基础设施中，受其安全策略保护。由于本工具无账号体系，我们无法识别数据的具体归属人，也无法针对特定用户进行数据隔离或访问控制。

三、数据管理

  • 导出/备份：本工具提供 JSON 导出功能，您可随时将当前业务数据导出为 JSON 文件保存在本地。
  • 删除/重置：浏览器本地数据可通过浏览器设置清除；云端业务数据可通过工具提供的"重置"功能恢复为初始状态。
